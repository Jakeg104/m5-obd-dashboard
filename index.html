Clear trouble codes?

This sends OBD Mode 04 to the DME. It will:

  • Erase all stored and pending codes and turn off the check-engine light
  • Erase the freeze-frame snapshot (it will be saved to history first)
  • Reset all emissions readiness monitors to Incomplete — the car will fail an emissions/inspection test until they re-complete

Ignition ON, engine OFF is the safest state. Clearing does not fix anything — if the fault is real the code will return.
