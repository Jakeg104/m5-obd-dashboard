# M5 OBD Dashboard

Browser dashboard for a Bluetooth LE ELM327 OBD-II adapter (Veepeak OBDCheck BLE), styled after the 2002 BMW M5 (E39) cluster.

- **Live:** open the GitHub Pages link in Chrome/Edge (Windows, Android, Mac) or the **Bluefy** browser on iPhone.
- **Local:** double-click `Start Dashboard.bat` (serves on http://localhost:8642).
- **Demo mode** simulates a car so you can try it without the adapter.
